# 结构

## 十阶段

| 阶段 | 产物 | done |
|---|---|---|
| 0 立项 | 一句话故事、核心冲突三问、三灾难、结局画面 | 一句话能让人追问"然后呢" |
| 1 设定 | 世界规则（含"不能做什么"）、人物卡、术语表、时间线 | 主角/对手各有动机、目标、缺陷、弧光 |
| 2 全书结构 | 三幕里程碑、五个不可逆转折、中点反转 | 每个转折都回不去 |
| 3 卷纲 | 5–10 卷：mini-goal、卷末高潮、下卷钩子 | 卷与卷有因果，不是并列 |
| 4 章纲 | 滚动维护未来 3–5 章，四节点 | 每章有转折、有钩子、回应上一章 |
| 5 上下文卡 | `novel_brief` 输出 | 含在场人物与待收伏笔 |
| 6 正文 | `03-正文/第NNN章.md` | 场景有目标—冲突—转折；字数达标 |
| 7 落追踪 | 总表、伏笔账本、人物"最近出场" | 新增事实全部入账 |
| 8 审校 | `novel_check` + 三轮清单 | error 清零，warn 有处置 |
| 9 卷末审计 | 结构审计 + 修订 | 修订预算未超 |

## 比例

- 三幕：建置 25% / 对抗 50% / 解决 25%。
- 百万字量级：第一幕 15–20 万字，第二幕 60–70 万字（含多个中点反转），第三幕 10–15 万字。
- 网文可以压缩建置到几万字，但"目标—阻碍—升级—小高潮"的序列逻辑不变。

## 卷与序列

- 每卷是一个小闭环：本卷 mini-goal、核心冲突、卷末小高潮、通下卷的钩子。
- 卷末用"部分解决 + 更大威胁浮现"：纯开放让人弃书，纯团圆让人没有追读动力。
- 每卷再拆 2–4 个序列，每个序列有短期目标，结束时主角或世界状态发生可见变化。
- 序列之间要有因果链：上一段的后果是下一段的动力。

## 节奏

- 张力是波浪，不是匀速。连续 5 章同一强度，就需要一场人物戏或信息揭示来调节。
- 每卷末最后三章把钩子拉满，同时让本卷核心冲突有一个可辨识的结果。
- 第一卷第 1 章细纲通常 3–7 天，试写第一卷 3 周，再补后续卷纲——比先规划完 100 万字更可持续。

## 结构变更

改结构必须写 `02-结构/结构变更日志.md`：日期、变更内容、影响范围（卷/章/伏笔）、是否已回溯修订。

重大调整（例如把第三卷高潮提前）要触发三项同步扫描：伏笔、时间线、人物一致性。没有登记的改结构，是"按旧结构写的段落"的来源。
