# 细纲

`02-结构/章纲.md` 每章一行，放四节点，够写大多数章节。

一章超过 3 场戏、需要精确控制节奏、或涉及多线交汇时，在这里放详版，文件名 `第012章.md`（与正文章号一致）。`novel_brief` 会自动把详版带进上下文卡。

模板：

```
## 场次

1. 地点 / 时间
   - 谁想要什么：
   - 阻力：
   - 转折：
   - 出场：
   - 埋/收伏笔：

2. 地点 / 时间
   - 谁想要什么：
   - 阻力：
   - 转折：
   - 出场：
   - 埋/收伏笔：

## 本章结尾
- 钩子：
- 下章回应对接：
- 读者应获得的信息：
```

规则：

- 每场戏的“转折”不能空；空说明这场戏可以并进别场。
- 场次顺序按**因果**排，不按时间排；先发生什么不重要，先让读者知道什么才重要。
- 详版写完后，把本章的目标/转折/钩子同步回章纲那一行，别让两张表打架。
