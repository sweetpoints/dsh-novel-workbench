# 审校清单

> 一次只做一层：结构 → 人物 → 语言。混着改会越改越乱。

## 第一轮：结构（初稿后至少隔 48 小时）

- [ ] 每章"推进了什么"能一句话说清；连续三章答案雷同 = 注水
- [ ] 主线没有中段失踪
- [ ] 每个幕末都有不可逆转折
- [ ] 伏笔都有埋设与计划回收；超期的已处理或标失效
- [ ] 可合并/删除的章节已列出并执行
- [ ] 结构变更已写入变更日志

## 第二轮：人物

- [ ] 每个人物的动机前后一致
- [ ] 语言风格没有漂移（前半寡言、后半话痨是最常见的病）
- [ ] 成长弧线有过程，不是突然顿悟
- [ ] 关键选择可信："这个人会不会这样做"
- [ ] 抽读三场：开场确立人物 / 中段最大危机 / 结局最终选择

## 第三轮：语言

- [ ] 朗读一遍，气息不顺处已改
- [ ] 删冗余、换弱词、调句式
- [ ] 时态、人称、称谓全书统一
- [ ] 专名拼写与术语表一致

## 交付前

- [ ] 试读读者聚类反馈的问题已处理
- [ ] 定稿版本已单独存档
- [ ] 平台/投稿格式已核对
